# Castaway Lookout — ESP32 RC4

This prerelease adds the downloadable native ESP32 firmware package for the
Waveshare ESP32-S3-Touch-LCD-7, 800×480, **16 MB flash / 8 MB PSRAM**.
The project is now **Castaway Lookout**. Existing Johnny Castaway executable
names, Windows installer identity, settings and runtime labels are unchanged.

## Install

Download **JohnnyCastaway-ESP32-S3-Touch-LCD-7-2026.1.0-rc.4.zip** from this
release's assets. Extract it, put your original `RESOURCE.MAP` and `RESOURCE.001`
in `data`, and double-click **FLASH_ESP32.bat** on a Windows 10/11 x64 computer.
Follow **FLASHING.md** in the ZIP or the
[ESP32 installation guide](https://github.com/DrWize/Castaway-Lookout/blob/main/docs/FLASH_ESP32_7_TOUCH.md).
No Git, separately installed Python or ESP-IDF is needed.

The flasher checks chip/memory identity; users must confirm the exact display
model. 7B, 8 MB flash and other board/display variants are not supported.
Normal updates preserve the existing Johnny settings partition. Allow about
90 seconds for startup checks, then follow the display's Wi-Fi setup prompts.

## Included

- Normal randomized playback across the 63-scene catalog.
- Local Wi-Fi setup, authenticated browser controls, Normal/Review playback,
  persistent settings and scene bug reports.
- Optional Clock & weather and Reviewer sidebars, colour weather icons, city
  selection and local update time.
- Firmware binaries, checksums, double-click Windows flasher, installation
  guide, source license, attribution and corresponding source revision.

Original Sierra/Dynamix data and private `jcdata.bin` are excluded. The helper
creates the private data image locally from the user's supported original pair.

## Validation and limitations

This release repackages the existing **2026-09-04** normal firmware without
recompiling it. Embedded version: `2026.1.0-rc.4`; application SHA-256:
`82cc2dcb528532d5f5eeec866d1676c588f181afa102e6e57ce30caa88c28267`.
`SOURCE.md` in the ZIP identifies the committed source snapshot; the embedded
build date remains September 4. A separate `.zip.sha256` asset checks the whole
ZIP, and `firmware/SHA256SUMS.txt` checks its firmware files.

Historical project records report passing automated/build/package-flasher and
serial checks, plus the closed 63-scene physical review. Publication work only
inspected docs, configuration, artifact metadata, hashes and archive contents;
no tests, firmware build or flashing were rerun.

**Still open:** direct physical acceptance of the latest Clock/weather layout,
city selection, colours, smoothness, Reviewer/Off switching, reboot persistence
and stale-weather handling. This is **not a stable release**. Audio, SD-card
resource loading, OTA and public-internet access remain outside ESP32 scope.

## Windows users

Continue using the unchanged
[Windows RC3 installer](https://github.com/DrWize/Castaway-Lookout/releases/download/v2026.1.0-rc.3/JohnnyCastaway-Windows-11-x64-Setup.exe)
and [Windows setup guide](https://github.com/DrWize/Castaway-Lookout/blob/main/docs/SETUP_GUIDE.md).
