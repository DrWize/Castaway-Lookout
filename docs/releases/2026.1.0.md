# Castaway Lookout 2026.1.0 stable

Windows 11 x64 and Waveshare ESP32-S3-Touch-LCD-7 are available together in
[2026.1.0 stable](https://github.com/DrWize/Castaway-Lookout/releases/tag/v2026.1.0). There is no macOS version.

## Windows 11 x64

Download the [Windows installer](https://github.com/DrWize/Castaway-Lookout/releases/download/v2026.1.0/JohnnyCastaway-Windows-11-x64-Setup.exe)
and follow the [Windows setup guide](https://github.com/DrWize/Castaway-Lookout/blob/main/docs/SETUP_GUIDE.md).
The per-user installer offers verified data setup, optional sounds and
screensaver registration. Upgrades preserve the shared INI. Original game data
is supplied separately; the binaries are unsigned.

For manual setup, download the [application](https://github.com/DrWize/Castaway-Lookout/releases/download/v2026.1.0/JohnnyCastaway-Windows-x64.exe)
and [screensaver](https://github.com/DrWize/Castaway-Lookout/releases/download/v2026.1.0/JohnnyCastaway-Windows-x64.scr).
Product version is **2026.1.0**; numeric file/installer version is **2026.1.0.4**.

Regression tests, native EXE/SCR builds, amd64 checks, go vet and the installer
build passed in a clean source checkout. GitHub CI passed. The user accepted
the installer on 2026-09-05; the stable build changes version metadata and
repository links without changing installation behavior. Full separate-account
screensaver scenarios were not independently rerun and remain follow-up work.

## ESP32

Download the [ESP32 flashing ZIP](https://github.com/DrWize/Castaway-Lookout/releases/download/v2026.1.0/JohnnyCastaway-ESP32-S3-Touch-LCD-7-2026.1.0.zip)
and follow the [ESP32 setup guide](https://github.com/DrWize/Castaway-Lookout/blob/main/docs/FLASH_ESP32_7_TOUCH.md).
Supported hardware is the Waveshare ESP32-S3-Touch-LCD-7, **800x480, 16 MB flash,
8 MB PSRAM**. Other display variants, including 7B, are unsupported.

Extract the complete ZIP, put original RESOURCE.MAP and RESOURCE.001 in data,
and run FLASH_ESP32.bat on Windows x64. The helper checks chip/memory identity,
preserves settings during normal updates and creates private jcdata.bin locally.
No Git, separate Python installation or ESP-IDF is required. Allow about
90 seconds for startup checks.

Features include the 63-scene catalog, Wi-Fi setup, authenticated LAN controls,
Normal/Review playback, persisted settings, scene bug reports and optional
Clock/weather and Reviewer sidebars. Weather shows LAST UPDATED, SAVED WEATHER
or WAITING FOR WEATHER; the controller includes the update date.

The user accepted login, presentation, controls, persistence, fidelity and
weather wording on 2026-09-05. Stable runtime bytes match the physically
accepted build apart from application metadata and checksums. Normal build and
source CI passed; the identified N16R8 received a hash-verified app-only flash
and reboot with settings preserved. Serial reported 2026.1.0 and fresh weather
at 91.407 seconds after reboot. These serial results are separate from the
prior user visual acceptance. Audio, SD-card resource loading, OTA and
public-internet exposure are outside this release.
